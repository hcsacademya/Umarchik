GitHub: asosiy branchni almashtirish

≈ 2 daqiqa

Repoda hozir asosiy (default) branch — claude/bold-planck-jnqmmn, unda eski o'yin turibdi. Yangi o'yin claude/sweet-davinci-4b69a2 branchida. Cloudflare asosiy branchni joylaydi, shuning uchun avval uni almashtiramiz.

  1. Brauzerda oching: https://github.com/hcsacademya/umarchik
  2. Yuqoridagi Settings (Sozlamalar) bo'limiga kiring.
  3. General sahifasida Default branch qismini toping.
  4. Branch nomi yonidagi ⇄ (almashtirish) tugmasini bosing.
  5. Ro'yxatdan claude/sweet-davinci-4b69a2 ni tanlang → Update → ogohlantirishda I understand, update the default branch ni bosing.

Cloudflare: o'yinni internetga joylash

≈ 10 daqiqa

1.1. Akkaunt ochish

  1. Oching: https://dash.cloudflare.com/sign-up
  2. Email va parol kiriting → Sign up.
  3. Emailingizga kelgan xatdagi havolani bosib, emailni tasdiqlang.
  4. Cloudflare domen qo'shish yoki tarif tanlashni taklif qilsa — o'tkazib yuboring (domen shart emas).

1.2. Loyiha yaratish

  1. Chap menyudan Workers & Pages (yoki Compute (Workers)) bo'limiga kiring.
  2. Create (yoki Create application) tugmasini bosing.
  3. Import a repository (Git repozitoriyni ulash) ni tanlang.
  4. Connect GitHub → GitHub oynasi ochiladi:
    • GitHub'ga kiring (kirmagan bo'lsangiz).
    • Only select repositories ni tanlang → hcsacademya/umarchik ni belgilang.
    • Install & Authorize (yoki Install) ni bosing.
  5. Cloudflare'ga qaytgach, ro'yxatdan umarchik reposini tanlang → Next / Begin setup.

1.3. Sozlamalar muhim

Quyidagilarni aynan shunday yozing:

MaydonQiymat
Project name (Worker nomi)umar
Build commandnpm run build
Deploy commandnpx wrangler deploy (odatda o'zi yozilgan bo'ladi)
Path / Root directorybo'sh qoldiring (yoki /)
Nom aynan «umar» bo'lishi shart. Repodagi wrangler.jsonc faylida ham shu nom yozilgan. Boshqa nom kerak bo'lsa, ayting — faylni o'zgartirib beraman.

Keyin Create and deploy (yoki Deploy) ni bosing. Yig'ish 1–3 daqiqa davom etadi, ekranda jarayon yozuvlari chiqadi, oxirida Success chiqishi kerak.

1.4. Branchni tekshirish

  1. Yaratilgan umar Worker sahifasida Settings → Build bo'limiga kiring.
  2. Branch control → Production branch claude/sweet-davinci-4b69a2 ekanini tekshiring. Boshqa bo'lsa — shuni tanlab Save bosing, keyin Deployments bo'limida qayta yig'ing (Retry build / Redeploy).

1.5. O'yin manzili

  1. Worker sahifasida Visit tugmasi yoki Settings → Domains & Routes bo'limida manzil turadi:
    https://umar.<sizning-nomingiz>.workers.dev
  2. Shu manzilni nusxalab oling — 3-qismda kerak bo'ladi.
  3. Brauzerda ochib ko'ring: xarita va pastda tablar chiqishi kerak.
«Mehmon» yozuvi normal. Oddiy brauzerda chap panelda «Mehmon» chiqadi, chunki o'yin Telegram'dan ochilmagan. Birinchi ochishda «manzil topilmadi» chiqsa, 1–2 daqiqa kutib qayta oching.

Telegram bot ochish (@BotFather)

≈ 5 daqiqa
  1. Telegram'da qidiruvga @BotFather yozing. Ko'k galochkali rasmiy botni oching → Start.
  2. /newbot buyrug'ini yuboring.
  3. BotFather botning nomini so'raydi (odamlar ko'radigan nom). Masalan: Umar
  4. Keyin username so'raydi — oxiri albatta bot bilan tugashi kerak. Masalan: umar_oyin_bot. Band bo'lsa, boshqasini yozing: umar_qasr_bot, umarchik_bot …
  5. BotFather tabrik xabari va token beradi (uzun kod, masalan 1234567890:AA…).
Tokenni hech kimga bermang va hech qayerga joylamang — u botni boshqarish kaliti. Hozir kerak emas; keyinroq (Telegram Stars, /start javobi) kerak bo'ladi. Xavfsiz joyda saqlang.

Botga o'yinni ulash (Mini App)

≈ 5 daqiqa

3.1. Asosiy Mini App eng muhimi

  1. BotFather'ga /mybots yuboring → botingizni tanlang.
  2. Bot Settings → Configure Mini App → Enable Mini App.
  3. BotFather manzil so'raydi — 1.5-qadamdagi manzilni yuboring:
    https://umar.<sizning-nomingiz>.workers.dev
Natija: bot profilida Open (Ochish) tugmasi paydo bo'ladi. O'yin havolasi: https://t.me/<bot_username>?startapp — buni do'stlaringizga yuborsangiz bo'ladi.

3.2. Chatdagi «O'ynash» tugmasi

  1. /mybots → botingiz → Bot Settings → Menu Button → Configure menu button.
  2. Manzilni yuboring (o'sha https://umar….workers.dev).
  3. Tugma nomini yuboring: O'ynash
Natija: bot bilan chatda, yozish joyining chap tomonida O'ynash tugmasi chiqadi.

To'liq ekran va gorizontal holat

O'yin Telegram ichida o'zi to'liq ekranga o'tadi va telefon gorizontal turganda shu holatda qulflanadi (Telegram 8.0 va undan yangi versiyalarda).

Yarim ekranda ochilsa, havolaga &mode=fullscreen qo'shib ko'ring: https://t.me/<bot_username>?startapp&mode=fullscreen
4

Sinash

≈ 5 daqiqa
  1. Telefonda botingizni oching → O'ynash (yoki profildagi Open).
  2. Telefonni gorizontal buring (avtomatik burish yoqilgan bo'lsin).
  3. Tekshiring:
    • Chapdagi panelda Telegram rasmingiz va ID raqamingiz chiqyaptimi («Mehmon» emas).
    • 1-jangni o'ynab yuting → oltin qo'shildimi.
    • Telegram'ni butunlay yopib, qayta oching → yutuqlar saqlanib qolganmi (Telegram bulutida).
    • Boshqa telefon yoki kompyuterdagi Telegram'dan kirsangiz ham yutuqlar turishi kerak.
  4. Muammo bo'lsa — skrinshot olib yuboring.
5

O'yinni yangilash

Hech narsa qilish shart emas: yangi o'zgarish branchga yuklanganda Cloudflare uni 1–3 daqiqada o'zi qayta yig'ib joylaydi. Telegram'da o'yinni yopib, qayta ochsangiz yangi versiya chiqadi.

Yig'ish holatini ko'rish: Cloudflare → Workers & Pages → umar → Deployments.
